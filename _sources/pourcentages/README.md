# Enquêtes sur les pourcentages

Source de `outils/pourcentages_recherche.pdf` (4 pages).

Depuis ce dossier, compiler avec TeX Live :

```sh
pdflatex -interaction=nonstopmode -halt-on-error pourcentages_recherche.tex
cp pourcentages_recherche.pdf ../../outils/pourcentages_recherche.pdf
```

Les six schémas vectoriels sont conservés dans `diagrammes.pdf`.

Ordre : détectives et évolutions ; trois problèmes puis deux barres ; magasins ; taux et prix initial. Les réponses se rédigent sur le cahier.

Vérifications : casque 66 € (budget insuffisant de 1 €) ; randonnée 3 km restants ; panier 52 € sans carnet, 48 € avec. Deux barres : Bob 400 et Alice 500 ; garçons 250 et filles 200. Magasins A–G : 40 ; 42 ; 36 ; 45 ; 45 ; 43,20 ; 45 €. Réduction unique de 30 % : 42 €, différente des deux remises successives. Taux : 25 %, 40 %, 23 %. Prix initiaux : 80 €, 90 €, 400 €. Ajouter 25 % à 60 € donne 75 €, pas 80 €. Mission 2 : 100 → 120 → 96.
