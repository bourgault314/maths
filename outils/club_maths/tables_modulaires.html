Activité 1 : Les Tables Modulaires

Observez comment de simples tables de multiplication créent des formes géométriques complexes.

Comment ça marche ?

La Règle du jeu :

  1. On place N graduations numérotées sur un cercle (comme une horloge).
  2. On choisit une table de multiplication (par exemple la table de 2).
  3. Pour chaque graduation x, on calcule le résultat x × 2.
  4. On relie la graduation de départ à la graduation d'arrivée.
  5. Astuce : Si le résultat dépasse le nombre de points, on fait un tour de cercle (on soustrait N). C'est ce qu'on appelle le modulo.

Exemple avec 60 points : 32 × 2 = 64. Comme 64 dépasse 60, on relie 32 au point 4.
