Relâcher pour jeter
Valeur de l’angle (°)
—
Astuce : 0 à 360. Le pavé fonctionne sans clavier (tablette).
Entrez une longueur comprise entre 1 et 20 cm.
Écrivez les décimaux avec une virgule. Les longueurs sont proportionnelles : 3, 4 et 5 cm gardent exactement le rapport 3:4:5.
Aide (raccourcis & gestes)
Gestes essentiels
  • Déplacer : glisser une bande, un segment ou un aimant.
  • Supprimer : bouton Supprimer, puis clic sur l’objet — ou glisser l’objet vers le bandeau du haut.
  • Échap annule les modes Trace, Fixer ou Supprimer.
Création précise
  • Créer un segment : saisir une longueur de 1 à 20 cm (par exemple 3,5).
  • Les longueurs affichées sont proportionnelles, même après un zoom.
Construire et laisser un arc
  1. Fixer → cliquer au milieu du segment qui ne doit plus bouger. Un bref signal orange confirme l’action.
  2. Trace → cliquer sur un point pour l’activer ou le désactiver. Plusieurs points peuvent être actifs.
  3. Faire pivoter le segment relié : la base reste fixe et le point dessine son arc.
Pour arrêter un point : Trace, puis ce point. « Effacer les annotations » efface les arcs déjà dessinés. Pour libérer une base : Fixer, puis recliquer sur son segment.
Manipulation
  • Glisser une bande / un aimant pour déplacer.
  • Double-clic sur un aimant (connecté à plusieurs bandes) : détacher (crée un nouveau magnet).
  • Jeter : glisser vers le haut. La construction supprimée est surlignée avant de lâcher.
Zoom
  • Molette : zoom au pointeur.
  • Boutons + / - : zoom avant/arrière.
  • R : recentrer la vue (zoom 100%).
  • F : plein écran / quitter plein écran.
Outils géométriques
  • ← / → : tourner l’outil géométrique actif (rapporteur / équerre).
  • Shift + ← / → : pas de 5° (sinon 1°).
  • Le centre du rapporteur et le coin de l’équerre sont aimantés.
Fixer ou rendre rigide
Fixer immobilise un segment. Le bouton Rigide laisse la construction bouger et tourner, mais l’empêche de se déformer.
  • Attraper un aimant au milieu d’une connexion : déplacement rigide du groupe.
  • Attraper un aimant au bout (extrémité) : rotation rigide du groupe autour du point voisin.
  • Maintenir Ctrl : mode rigide temporaire (relâcher = retour).
Astuce : touche Échap pour fermer ce panneau.
