# Catalogue — emplacement réservé

Ce dossier accueillera les entrées pédagogiques structurées après validation du
contrat. Aucun contenu d'Automatismes ne doit y être copié avant le pilote de
migration.

Chaque future entrée devra au minimum renseigner son identifiant, son niveau,
ses compétences, ses prérequis, ses erreurs fréquentes, ses représentations,
son statut de validation, sa source et sa licence.
