# Schémas — emplacement réservé

Les schémas JSON définitifs ne sont pas encore figés. Ils seront élaborés à
partir de trois composants pilotes afin d'éviter de construire un contrat
théorique incapable de représenter les outils réels.

Les premières familles prévues sont : composant, gabarit pédagogique, activité,
question générée et tentative.

Le premier contrat expérimental de composant est désormais celui de Pythagore :
`pythagore-components.v1.json`. Sa documentation pédagogique et ses règles de
rendu sont dans `studio/components/pythagore/README.md`.
