# État réel du Studio maths&go — 17 juillet 2026

## Décision

Le dossier `studio/` de ce dépôt est la bibliothèque centrale unique des composants
réutilisables de maths&go.

Il ne faut pas créer un second dossier concurrent nommé « univers Matego »,
« plan Matego » ou « studio Matego ». Le nom officiel du projet est `maths&go`.

## Ce qui existe déjà

- `studio/docs/` contient une première vision, une architecture cible, une charte,
  une feuille de route et un inventaire de migration ;
- `studio/components/pythagore/` contient déjà un composant exécutable et une
  documentation détaillée ;
- `studio/schemas/pythagore-components.v1.json` constitue un premier contrat
  expérimental ;
- `auto/` contient l'application Automatismes et des composants visuels encore
  situés dans son propre arbre ;
- les pages historiques du site restent des références publiées et ne doivent pas
  être supprimées pendant la migration.

## Ce qui n'est pas encore fait

- le Studio n'a pas encore de registre général de composants ;
- le moteur de composition n'est pas encore construit ;
- les composants de pourcentage ne sont pas encore extraits dans `studio/` ;
- les rendus web et imprimables ne partagent pas encore un contrat commun ;
- Automatisme n'est pas encore un consommateur systématique du Studio.

## Premier pilote

Le premier pilote sera la famille des représentations de pourcentage.

Sources à auditer :

- `outils/pourcentages_exerciceur.html` ;
- `outils/_gabarits_pourcentages.tex` ;
- `outils/_gabarit_pourcentages_double_ligne_graduee.tex` ;
- `auto/scripts/shared/visuals/arithmetic/fraction-percent-bar.js` ;
- `auto/dev/visual-library.html`.

Le code existant doit être récupéré et comparé avant toute nouvelle implémentation.
Les variantes réellement différentes seront conservées comme variantes d'un même
composant ou comme composants distincts, après validation.

## Règle de migration

La migration suit le cycle :

`audit → extraction minimale → prévisualisation → vérification visuelle →
validation → intégration dans un premier consommateur`

Aucune suppression massive ni fusion de l'application Automatisme dans le Studio
n'est autorisée.

## Dépôts

- `bourgault314/maths` : site public et bibliothèque centrale `studio/` pour le
  moment ;
- `bourgault314/mathsgo-automatismes-beta` : application bêta séparée ;
- l'application bêta peut consommer un composant validé par un adaptateur, mais ne
  devient pas la source du composant.
